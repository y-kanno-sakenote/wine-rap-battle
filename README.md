# ワインラップバトル

ブドウの品種どうしがラップで張り合う遊びのページです。対戦カードを2枚選ぶと、名勝負の歌詞を組み替えてバトルが出ます。

- 遊ぶ: https://y-kanno-sakenote.github.io/wine-rap-battle/
- キャラ: カベルネ・ソーヴィニヨン／メルロー／ピノ・ノワール／シャルドネ／ソーヴィニヨン・ブラン

## 歌詞について

- 歌詞はAI（Claude）で書いたものです。`docs/wine_corpus.jsonl` の名勝負から、同じ相手・同じ韻の2行ずつを組み替えて表示します
- 品種についての話は、日本醸造協会誌の記事にもとづく範囲に絞っています（記事の年・「日本では」などの限定はそのまま残しています）
- 日本酒版: [醸造ラップバトル](https://jozorap.sakenote.net/)
- 作成: 合同会社サケノテ（sakenote.net）
